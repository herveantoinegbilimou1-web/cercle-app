# Cercle des Africains — application

Application web installable (PWA) du Cercle des Africains, organisation culturelle panafricaine en Fédération de Russie.

- Français / русский
- Agenda, antennes, commissions, adhésion, contact
- Fonctionne hors connexion après la première visite

Installation sur téléphone : ouvrir le site, puis « Ajouter à l'écran d'accueil ».
